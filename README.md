# WEZU Platform: AWS EKS Architecture

An interactive, single-page diagram of the WEZU platform's cloud architecture on AWS EKS. Click any layer to see its components, technologies, key features, performance metrics, cost breakdown and security notes.

## Layers

1. IoT and edge layer
2. AWS Route 53
3. Networking layer
4. EKS cluster #1: ingestion and streaming
5. EKS cluster #2: business microservices
6. EKS cluster #3: AI/ML and intelligence
7. Data and storage layer
8. Monitoring, alerting and operations
9. Client applications and interfaces

## AI agents

The page also documents the platform's intelligent agents: Battery Intelligence, BESS Management, Grid Integration, Solar Optimization, Customer Experience, and Safety and Security.

## Viewing

It's a single self-contained `index.html`, so open it in a browser:

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

You can also serve it with GitHub Pages.
